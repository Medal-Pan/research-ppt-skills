# 软件与下载

核对日期：2026-10-31。下载入口指向原厂；安装程序和许可不随本技能再分发。

| 软件 | 用途与平台 | 官方入口与安装方式 |
| --- | --- | --- |
| Python 3.10+，Origin 推荐 64 位原生 Windows 环境 | 运行命令桥；不要用 WSL Python 驱动 Windows Origin | [Python 下载](https://www.python.org/downloads/)，安装后检查 `python --version` |
| Origin / OriginPro | Windows 原生项目与图页；需要有效授权 | [OriginLab 下载/试用](https://www.originlab.com/demodownload.aspx)，登录后按学校/个人许可或试用流程安装 |
| `originpro` Python 包 | 在外部 Python 连接 Origin；软件本体仍须安装 | 在实际执行任务的解释器中运行 `python -m pip install originpro` |
| GraphPad Prism | 项目、统计分析与图形导出；本命令桥启动器为 Windows | [Prism 官方试用与下载](https://www.graphpad.com/scientific-software/prism/free-trial)，按原厂许可流程安装 |
| Zotero | 本地文献检索与 RIS/BibTeX 导出 | [Zotero 下载](https://www.zotero.org/download/)，安装桌面端并启用本地 API |

Python 包不等于软件本体。默认不需要同时安装三款应用；只准备当前任务需要的软件。程序不在常见路径时，用环境变量指定其可执行文件位置。完整 PPT 工具与各 Agent 下载见仓库的 [软件指南](https://github.com/Medal-Pan/research-ppt-skills/blob/main/docs/SOFTWARE.md)。
