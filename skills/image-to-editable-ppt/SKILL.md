# 图片复现可编辑 PPT

以“复杂视觉保真 + 主要文字可编辑”复现原图。优先保持整体设计质感、构图、视觉完成度和高级感，同时让主要文字能在 PPT 中直接编辑。使用当前环境可用的 PPTX 工具完成实际文件。

## 识别页面并选择对象形式

先查看源图，识别文字、视觉素材、简单图形和层级关系；多页输入按原顺序处理。默认输出 16:9，用户另有要求则遵从；原图比例不同，应等比缩放并谨慎适配留白，避免拉伸变形或裁掉内容。缺少待复现的原图时，先索取原图。

按区域采用混合还原：

| 区域 | 处理方式 |
| --- | --- |
| 品牌 Logo、商标、产品 UI、人物、商品图、官方图标；照片、插画、3D 图、复杂背景、纹理、光影、玻璃或金属质感 | 优先从原图裁切或提取，保留源分辨率，作为独立图片放入 PPT；只裁取所需区域，保持原裁切方式。 |
| 复杂图表、复杂流程图、循环图、拼图等视觉区域 | 难以忠实重建时保留为独立图片。可分离的主要文字仍应重建。 |
| 主标题、副标题、正文、金句、关键数字、关键词、结论框文字、注释、页脚、章节名、页码 | 尽量使用 PPT 原生文本框，保持可编辑。 |
| 简单线条、分隔线、基础几何框、轻量标签、按钮、色块、基础表格和简单图表 | 尽量使用 PPT 原生形状、表格或图表重建。 |

不得将整页简单铺成一张背景图，也不得为视觉保真而把所有文字压成图片。复杂区域中的小字，如拆分会明显破坏质感，可随图片保留，并在最终说明中标注。

## 重建文字与版式

- 尽量匹配字体气质、字形层级、字重、颜色、字号、行距、字距、对齐方式和位置。无法识别字体时选风格接近的系统字体；中文可选黑体、思源黑体、微软雅黑，英文和数字按原图选择接近的无衬线或衬线字体。
- 图片中的文字改为可编辑文本时，用背景色、渐变或局部遮罩覆盖原字，再叠加文本框。检查周围纹理和边缘，避免重影或明显修补痕迹。
- 保留原图的版式比例、视觉重心、阅读顺序、留白节奏，以及颜色、对比度、明暗关系、光源方向、阴影强度和空间层次。
- 元素的位置、大小、层级、描边、圆角、裁切、阴影、透明度和对齐关系尽量贴近原图。复杂视觉应保留原始质感，不要替换成低质默认图形、默认图标、默认阴影或模板化卡片。
- 图表数值无法准确恢复时，不猜测或伪造数据；可按视觉比例近似重建，但须在说明中标注“数据为视觉近似”。

## 预览并修正

将最终 PPTX 渲染为预览，与原图并排或叠加核对。逐页检查构图、比例、间距、颜色、层级和字体，并检查错字、漏字、换行错误、文本溢出、重叠和位置漂移。对明显偏差继续修改并重新渲染，直到整体观感接近原图。

核查主要文字确为可选中编辑的文本对象，简单元素保持原生可编辑，保留的图片裁切与清晰度合理。若当前环境无法渲染或核验某项，明确说明未核验的部分，不声称已通过视觉验收。

## 交付

交付可编辑 `.pptx` 文件、PPTX 渲染预览和原图对照图。附简短说明：

1. 哪些元素为可编辑文本、形状、表格或图表。
2. 哪些区域为从原图裁切或提取的图片素材。
3. 哪些文字因嵌入复杂视觉而保留为图片，以及原因。
4. 如有视觉近似的数据、字体替代或尚未核验的内容，一并注明。
