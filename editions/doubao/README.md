# 豆包对话引导版

官方客户端：[豆包下载](https://www.doubao.com/download/desktop)。本项目提供对话材料和本机脚本配套，不宣称豆包支持统一的本地 Skill 安装协议。

```bash
python scripts/install_skills.py --agent doubao --all --dest ./doubao-guide
```

在对话中附上所需技能的 `SKILL.md` 与被引用材料，或粘贴其指令。先询问当前模式是否能处理附件、执行代码并交付文件；无本机执行工具时，按命令桥的步骤在本机运行后回传 JSON/文件。

可用开场语：

```text
请按附件技能处理这份材料。先说明你当前是否能执行本地命令及访问我的桌面软件。
能执行的步骤请直接完成；不能执行的步骤给出可复制的命令，等待实际输出后继续。
不要把脚本建议或效果描述当成已经生成的文件。
```
