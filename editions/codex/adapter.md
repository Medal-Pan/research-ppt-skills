# Codex 适配

使用实际可用的文件、终端、图片及桌面工具。技能目录路径以宿主提供的位置为准。当前官方本地发现目录为 `.agents/skills`；旧环境可通过安装器 `--dest` 指定原目录，避免重复安装。

优先使用宿主原生生图；只有选择了 API 路线时才使用服务对应的凭据。不要因模型能理解图片就假定它能生成图片。桌面软件必须位于当前可调用的本机环境；云端容器不等同于用户的 Windows 桌面。

Origin/Prism/Zotero 协作任务可另行选用 `research-app-bridge`；不改变本技能自身的运行边界。未提供宿主专用软件工具时，用本地终端运行相应命令，并检查实际产物。
