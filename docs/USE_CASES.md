# 使用场景

## 论文组会 / 文献汇报

选 `nature-paper2ppt`。提供可读 PDF、听众背景和报告时长；只给摘要时，结论和方法细节也只能以已给材料为限。输出应包括实际 PPTX、可追溯的原图或表格、演讲备注和 QA 说明。

## 快速复现已有页面

选 `image-to-editable-ppt`。提供尽可能清晰的页面图片和目标比例。适合保留照片、复杂背景与 UI 质感，同时编辑主要文字、色块和简单形状。交付时区分原生对象与保留图片区域。

## 精细恢复流程图 / 图片型 PPT

选 `nature-image2ppt`。先完成运行环境预检，再按页重建和验证。相比轻量技能，它具有明确的页面清单、对象级约束、箭头检查、渲染证据和最终 QA；任务所需工具不齐时应报告具体缺项。

## 风格统一的图片式演示稿

选 `codex-ppt`。先准备提纲、风格要求和希望使用的论文原图。按该技能完成大纲、后端和样张确认后生成；幻灯片主体为图片，需要对象级编辑时另做图片复现。

## Origin 科研图组

选 `ace-sci-origin`。提供真实数据、单位、分组和参考图。需在 Windows 上具备 Origin 与 PowerPoint 环境，交付 Origin 工程及带 OLE 对象的 PPT；不可把外观相似的静态图片称为可编辑 Origin 对象。
